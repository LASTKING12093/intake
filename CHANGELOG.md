# Changelog

## [2.0.1] — 2026-10-02

First public release, continuing the existing application's version scheme.

- Native Windows desktop workflow for link detection, video/audio downloads and a local library.
- Queue, batch links, supported playlists, pause/resume, cancellation and retries.
- Public Spotify/Apple Music identification with visible source matching and uncertain-match review.
- Contextual format, quality, codec, metadata, artwork, lyric and subtitle controls.
- OLED-black interface, full-color platform icons and always-on animated navigation and disclosure.
- Verified extractor updates, pinned build inputs, Windows installer, portable distribution and release checksums.

Site availability and catalog completeness depend on upstream services. Spotify/Apple Music DRM streams and browser-authenticated downloads are not supported.
