# INTAKE v2.0.1

The first public release of INTAKE, continuing its existing version scheme.

> Take it in. Keep it yours.

### Highlights

- Paste, detect and download with automatic quality selection.
- Video/audio controls, queue, local library and supported playlists.
- Public catalog identification with visible recording matching.
- Metadata, artwork, optional lyrics and subtitles where supported.
- Native dark interface, colored source icons and always-on motion.

### Download

**Intake-Setup-x64.exe** is recommended for most users. **Intake-Portable-x64.zip** runs after extracting the whole folder. Both include the media helpers. Verify downloads with **SHA256SUMS.txt**.

Windows 10 (1809+) / Windows 11, x64. Tested locally on Windows 11; no clean VM was available. Installation, application startup, local MP4/MP3 downloads and uninstall were tested in isolated folders on the development host.

### Notes

This release is unsigned; Windows SmartScreen may warn about an unrecognized application. User media and settings are preserved on uninstall. Spotify/Apple Music links identify public metadata and match a compatible source; DRM audio is not downloaded. Site availability, public catalog completeness and optional lyrics are not guaranteed.
